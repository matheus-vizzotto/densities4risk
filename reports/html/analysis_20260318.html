Cross-validation procedure¶

Let $\mathbb{K}$ denote the set of kernel functions and $\mathcal{B}(K)$ the set of bandwidth selection procedures available for kernel $K$. In addition, let $\mathbb{P}$ denote the set of post-processing configurations. Each $P \in \mathbb{P}$ specifies a rule for computing a local mean of the density curves and is defined by a mean-computation mode and an associated window length $w$. In the empirical application, the mean-computation mode may correspond to an expanding or rolling scheme, while the window length determines the number of past curves used in the computation. The set $\mathbb{P}$ also includes the configuration corresponding to no post-processing, for which the transformation operator reduces to the identity mapping $\mathcal{T}_{P}(f_t)=f_t$.

The complete parameter space is defined as \begin{equation} \Theta = \{(K, B, \eta, P) : K \in \mathbb{K},\; B \in \mathcal{B}(K),\; P \in \mathbb{P}\}, \end{equation} where $\eta$ captures auxiliary parameters, such as the degrees of freedom for the Student-t kernel or the robust scale estimator for Silverman’s rule. In the present setting, these correspond to the degrees of freedom parameter for the Student-$t$ kernel or the use of a robust standard deviation estimator in the Silverman bandwidth rule. Each configuration $\theta_j \in \Theta$ is therefore defined as \begin{equation} \theta_j = (K_j, B_j, \eta_j, P_j), \quad j = 1,\dots,M. \end{equation}

Let $r_{t1},\dots,r_{tn_t}$ denote the intraday log-returns observed on day $t$, for $t=1,\dots,T$. For a given configuration $(K_j,B_j,\eta_j)$, the raw daily density estimates are first obtained using the kernel density estimator

\begin{equation} f_t^{(K_j,B_j,\eta_j)}(x) = \frac{1}{n_t h_t^{(j)}} \sum_{i=1}^{n_t} K_j\!\left(\frac{r_{ti}-x}{h_t^{(j)}};\eta_j\right), \end{equation}

where $h_t^{(j)}$ is the bandwidth determined by the rule $B_j$. This produces the functional time series of densities \begin{equation} \mathcal{X}^{(K_j,B_j,\eta_j)}=\{f_1^{(K_j,B_j,\eta_j)},\dots,f_T^{(K_j,B_j,\eta_j)}\}. \end{equation}

The post-processing configuration $P_j$ is then applied through a transformation operator $\mathcal{T}_{P_j}$ acting on the sequence of density curves. This yields the transformed functional time series \begin{align*} \mathcal{Z}^{(\theta_j)} &= \{Z_1^{(\theta_j)},\dots,Z_T^{(\theta_j)}\}, \\ Z_t^{(\theta_j)} &= \big(\mathcal{T}_{P_j}(\mathcal{X}^{(K_j,B_j,\eta_j)})\big)_t. \end{align*}

The sample is partitioned into three segments: an initial estimation period, a validation period, and a test period. Let $t_0$ denote the size of the initial estimation window and let $t_v$ denote the final index of the validation period, where $t_0 < t_v < T$. The observations $t=1,\dots,t_0$ form the initial estimation sample. Forecasts corresponding to $t=t_0+1,\dots,t_v$ constitute the validation period used for model selection, while forecasts for $t=t_v+1,\dots,T$ form the test period used for final forecast evaluation. For each configuration $\theta_i$, forecasts are generated using an expanding window scheme. At each step $t=t_0,\dots,T-1$, the forecasting model is estimated using the sample ${Z_1^{(\theta_i)},\dots,Z_t^{(\theta_i)}}$ and produces a one-step-ahead forecast $\widehat{Z}_{t+1}^{(\theta_i)}$. This procedure yields the sequence $ \widehat{Z}_{t_0+1}^{(\theta_i)},\widehat{Z}_{t_0+2}^{(\theta_i)},\dots, \widehat{Z}_{T}^{(\theta_i)}. $ In the empirical application considered in this dissertation, the initial estimation window is set to $t_0=100$, and the validation period ends at $t_v=180$. Consequently, the validation and test partitions contain 80 and 67 evaluation curves, respectively.

\begin{equation} L_{ij} = \frac{1}{t_v - t_0} \sum_{t=t_0}^{t_v-1} D\!\left( Z_{t+1}^{(\theta_j)}, \widehat{Z}_{t+1}^{(\theta_i)} \right). \end{equation}

which yields an $M \times M$ loss matrix. Finally, the selected configuration is

\begin{equation*} \theta^* = \arg\min_{\theta_i \in \Theta} \frac{1}{M} \sum_{j=1}^{M} L_{ij}. \end{equation*}
